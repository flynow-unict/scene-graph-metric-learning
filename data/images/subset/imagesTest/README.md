# Immagini delle test queries

Le 771 immagini corrispondenti agli ID dello split `test_queries`, estratte da
`images_all_15k/`.

Tenerle separate dalla massa delle immagini rende immediati gli esperimenti rapidi —
caricarne una nel frontend e osservare la risposta della pipeline — e garantisce che in
validazione si peschi solo fra immagini mai viste dal modello in addestramento.
